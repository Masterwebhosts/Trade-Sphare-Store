# Trade Sphare Store Landing Page

صفحة هبوط عربية لعرض خدمة إنشاء متجر إلكتروني، مع اختيار إضافات وحساب السعر تلقائياً وإرسال طلب مُجهّز إلى WhatsApp.

## الملفات
- `index.html` الصفحة الرئيسية.
- `style.css` التنسيقات المتجاوبة.
- `script.js` حساب السعر وتجهيز رسالة الطلب.

## الأسعار
- متجر إلكتروني أساسي: 100 دولار.
- الإعلانات المنبثقة: +50 دولاراً.
- استقبال الطلبات عبر واتساب: +50 دولاراً.
- تحويل العملات: +50 دولاراً.

## النشر على GitHub Pages
1. أنشئ مستودعاً عاماً باسم `Trade-Sphare-Store`.
2. ارفع الملفات الثلاثة إلى جذر المستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم `main` و`/ (root)`، واضغط Save.

الرابط المتوقع: https://masterwebhosts.github.io/Trade-Sphare-Store/
